## 🚀 Quick Start Guide

### For Each Task:

1. **Navigate to task folder**
   ```bash
   cd DataScience-Task[Number]-[ProjectName]
   ```

2. **Install requirements**
   ```bash
   pip install -r requirements.txt
   ```

3. **Download dataset** (if required)
   - See task's README.md for dataset source

4. **Launch Jupyter**
   ```bash
   jupyter notebook
   ```

5. **Complete the notebook**
   - Add your name
   - Run all cells
   - Review outputs

6. **Record demo video**
   - 2-second title card (Name + Track + Task)
   - Show notebook running
   - Explain key findings

7. **Push to GitHub**
   ```bash
   git add .
   git commit -m "Complete Task [Number]: [Task Name]"
   git push origin main
   ```

8. **Post on LinkedIn**
   - Upload video
   - Tag @Oasis Infobyte
   - Use #oasisinfobyte
