# Email Spam Detection with Machine Learning

## 📊 Project Overview
NLP binary classifier to distinguish spam emails from legitimate (ham) emails using text processing and machine learning.

## 🎯 Objective
Build a text classification model using NLP techniques to detect spam emails with high accuracy.

## 🛠️ Tech Stack
- Python, pandas, scikit-learn (TF-IDF, Naive Bayes, SVM), NLTK/re, Jupyter Notebook

## 🚀 How to Run
1. Download "spam.csv" from Kaggle/UCI
2. Place in this folder
3. Install: `pip install -r requirements.txt`
4. Run: `jupyter notebook email_spam_detection.ipynb`
