# Dataset Information: SMS Spam Collection

## Source
- **Name**: SMS Spam Collection Dataset
- **Origin**: UCI Machine Learning Repository
- **Available on**: Kaggle (https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset)

## Dataset Details
- **Total Messages**: 5,574 SMS messages
- **Spam Messages**: 747 (13.4%)
- **Ham Messages**: 4,827 (86.6%)
- **Language**: English
- **Format**: CSV file (spam.csv)

## Columns
1. **v1**: Label (ham/spam)
2. **v2**: Message text
3. Additional columns may be present but are not needed

## Class Distribution
The dataset is **imbalanced** with significantly more legitimate messages than spam. This reflects real-world scenarios where spam is the minority class.

## Usage
This is a standard benchmark dataset for SMS/email spam detection in NLP research and education.
