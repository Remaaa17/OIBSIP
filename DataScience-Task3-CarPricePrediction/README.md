# Car Price Prediction with Machine Learning

## 📊 Project Overview
Regression model to predict used car selling prices based on brand, age, mileage, fuel type, and transmission.

## 🎯 Objective
Build ML models that accurately predict car prices using multiple features.

## 🛠️ Tech Stack
- Python, pandas, scikit-learn, matplotlib, seaborn, Jupyter Notebook

## 📁 Dataset
**Source**: Kaggle - "Vehicle dataset from cardekho"  
**Search**: "car price prediction dataset" on Kaggle.com

Expected features:
- Car Name, Year, Selling Price, Present Price
- Kms Driven, Fuel Type, Seller Type, Transmission
- Owner

## 🚀 How to Run
1. Download car dataset from Kaggle
2. Place CSV in this folder
3. Install: `pip install -r requirements.txt`
4. Run: `jupyter notebook car_price_prediction.ipynb`
