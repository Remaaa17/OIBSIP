# Unemployment Analysis with Python

## 📊 Project Overview
Exploratory data analysis on unemployment data to uncover regional and temporal trends, focusing on COVID-19's impact on unemployment rates in India.

## 🎯 Objective
Perform EDA to analyze unemployment trends across regions and time periods, with special focus on pre-COVID vs post-COVID comparison.

## 🛠️ Tech Stack
- Python, pandas, matplotlib, seaborn, Jupyter Notebook

## 📋 Feature Checklist
- [x] Download unemployment dataset from Kaggle
- [x] Data loading, null checks, type conversion
- [x] Region-wise average unemployment rates
- [x] Month-wise trends analysis
- [x] Time-series line charts (3+ states/regions)
- [x] Bar chart: top 10 states with highest unemployment
- [x] Correlation heatmap
- [x] Pre-COVID vs post-COVID comparison
- [x] Written observations between charts
- [x] Clean, commented notebook

## 📁 Dataset
**Source**: Kaggle - "Unemployment in India"  
**Search**: "unemployment rate India dataset" on Kaggle.com

Expected columns:
- Region/State
- Date
- Unemployment Rate
- Employment Rate
- Labour Participation Rate

## 🚀 How to Run
1. Download "Unemployment_in_India.csv" from Kaggle
2. Place in this folder
3. Install: `pip install -r requirements.txt`
4. Run: `jupyter notebook unemployment_analysis.ipynb`
