## 🆘 Troubleshooting

### Common Issues

**Issue**: Package installation fails  
**Solution**: Upgrade pip first: `python -m pip install --upgrade pip`

**Issue**: Jupyter won't start  
**Solution**: Try `python -m notebook`

**Issue**: Dataset not loading  
**Solution**: Check file is in correct folder, verify filename matches code

**Issue**: Git push fails  
**Solution**: Check remote URL with `git remote -v`, ensure repo name is correct

**Issue**: Notebook kernel dies  
**Solution**: Restart kernel, ensure no memory-heavy operations
